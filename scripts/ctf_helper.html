문제 설명과 첨부 파일을 분석하여 최적의 분석 흐름을 자동으로 결정합니다.

KotH 세부 규칙이 공개되지 않아 현재는 관찰과 분석 기록만 지원합니다.

📁 파일이나 폴더를 끌어다 놓으세요. 폴더 내부 경로가 유지됩니다.

웹 주소면 동일 원본으로 GET/POST를 최대 8회 전송합니다. TCP 주소면 배너를 읽고 HTTP 서비스 여부를 자동 판별합니다.

문제에 적힌 형식인 DH{...}를 입력해도 해당 접두사의 플래그를 검색합니다.

분석은 로컬 서버 주소 http://127.0.0.1:8765/에서만 동작합니다. HTML 파일을 직접 열면 시작되지 않습니다.
